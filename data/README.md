# 데이터 파일

이 디렉토리 및 일부 형제 데이터 파일은 파일 크기 또는 라이선스 제약으로 인해 **저장소에 포함되지 않습니다**.
파이프라인을 실행하기 전에 직접 확보하거나 준비해야 합니다.

---

## 필수 파일

### 1. `정류장위치/과천시_버스_정류장_위치.json`

과천시 버스 정류장 위치 데이터.

**출처:** [공공데이터포털 (data.go.kr)](https://www.data.go.kr) — "버스정류장 위치정보" 검색

**형식:** JSON 배열. 각 요소는 다음 필드를 포함해야 합니다:
```json
[
  {
    "정류소id": "220000007",
    "정류소명": "10단지",
    "WGS84위도": 37.4353,
    "WGS84경도": 126.9965
  }
]
```

**사용처:** `POI.py`, `main.py`

---

### 2. `교통노드/과천시_교통노드.json`

과천시 교통 노드 데이터 (교차로, 분기점 등).

**출처:** [국가교통데이터오픈마켓 (its.go.kr)](https://www.its.go.kr) — "교통노드" 검색

**형식:** Kakao/ITS GeoJSON 형식:
```json
{
  "response": {
    "result": {
      "featureCollection": {
        "features": [
          {
            "geometry": {
              "coordinates": [126.9965, 37.4353]
            },
            "properties": {
              "nd_type_h": "교차로"
            }
          }
        ]
      }
    }
  }
}
```

**사용처:** `main.py` (`algorithm.py`를 통한 F7/F8 적합도 함수)

---

### 3. `교통링크/과천시_교통링크.json` *(선택)*

과천시 도로 구간(링크) 데이터. 파일이 없을 경우 빈 도로 목록으로 파이프라인이 계속 실행됩니다.

**출처:** [국가교통데이터오픈마켓 (its.go.kr)](https://www.its.go.kr) — "교통링크" 검색

**형식:** 교통노드와 동일한 GeoJSON 형식이며, `geometry.coordinates`에 도로 좌표 배열이 포함됩니다.

**사용처:** `main.py` (도로 그래프 구성)

---

### 4. `통과노선/정류장별_통과노선.json` *(선택)*

각 정류장을 통과하는 기존 버스 노선 수. 환승 정류장(2개 이상 노선 경유)을 식별하는 데 사용됩니다. 파일이 없을 경우 환승 정류장 적합도 항목(F10)은 0으로 평가됩니다.

**출처:** 지역 시 교통 당국 또는 TOPIS/BIS 데이터에서 수동 추출.

**형식:**
```json
[
  { "정류소ID": "220000007", "통과노선수": 3 },
  { "정류소ID": "220000065", "통과노선수": 1 }
]
```

**사용처:** `main.py` (`fitness.py`를 통한 F10 환승 점수)

## 필수 지원 파일 (`data/` 외부)

### 5. `llm_response.txt` (프로젝트 루트)

최적화 튜닝에 사용되는 LLM 생성 적합도 가중치. 가중치가 사용자/프롬프트별로 달라지므로 gitignore 처리되어 있습니다.

**형식:** 한 줄에 `key: value` 쌍 하나씩:
```
w1: 0.8
w2: 0.6
w3: 0.9
w4: 0.5
w6: 0.7
w7: 0.5
w8: 0.4
w9: 0.6
w10: 0.8
poi_weights: {"학교": 0.3, "병원": 0.3, "음식점": 0.2, "카페": 0.2}
```

`w1`–`w10` 키는 적합도 함수 F1–F10에 대응합니다. F5(유동인구)는 알고리즘에서 제외되므로 `w5`가 있어도 무시됩니다.
`poi_weights`의 키는 `bus_stop.csv`에서 사용되는 한국어 POI 카테고리명과 일치해야 합니다.

샘플 파일은 프로젝트 루트의 `llm_response_example.txt`에 제공됩니다.

---

### 6. `bus_stop.csv` (프로젝트 루트)

정류장별 POI 수 데이터. 이 파일은 **저장소에 포함**되어 있으며, Kakao Local Search API를 통해 `POI.py`를 실행하여 생성되었습니다.

재생성이 필요한 경우(예: 다른 도시), 다음 명령을 실행하세요:
```bash
python POI.py
```
`정류장위치/과천시_버스_정류장_위치.json`과 `.env`에 유효한 `KAKAO_REST_API_KEY`가 필요합니다.

---

## API 캐시

`path_cache.json` (프로젝트 루트)은 반복 호출을 방지하기 위해 Kakao Mobility API 응답을 저장합니다.
gitignore 처리되어 있으며, 첫 실행 시 자동으로 생성되고 이후 실행에서는 캐시를 재사용합니다.
