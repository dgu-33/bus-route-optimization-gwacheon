# Data Files

This directory and several sibling data files are **not included in the repository** due to file size or licensing restrictions.
You must obtain or prepare them before running the pipeline.

---

## Required files

### 1. `정류장위치/과천시_버스_정류장_위치.json`

Bus stop location data for Gwacheon city.

**Source:** [공공데이터포털 (data.go.kr)](https://www.data.go.kr) — search for "버스정류장 위치정보"

**Format:** JSON array. Each element must have:
```json
[
  {
    "정류소id": "220000007",
    "정류소명": "10단지",
    "WGS84위도": 37.4353,
    "WGS84경도": 126.9965
  }
]
```

**Used by:** `POI.py` (line 40), `generate_route.py` `main()` (line 1085)

---

### 2. `교통노드/과천시_교통노드.json`

Traffic node data (intersections, junctions) for Gwacheon city.

**Source:** [국가교통데이터오픈마켓 (its.go.kr)](https://www.its.go.kr) — search for "교통노드"

**Format:** Kakao/ITS GeoJSON envelope:
```json
{
  "response": {
    "result": {
      "featureCollection": {
        "features": [
          {
            "geometry": {
              "coordinates": [126.9965, 37.4353]
            },
            "properties": {
              "nd_type_h": "교차로"
            }
          }
        ]
      }
    }
  }
}
```

**Used by:** `generate_route.py` F7/F8 fitness functions (line 110)

---

### 3. `교통링크/과천시_교통링크.json` *(optional)*

Road segment (link) data for Gwacheon city. If absent, the pipeline continues with an empty road list.

**Source:** [국가교통데이터오픈마켓 (its.go.kr)](https://www.its.go.kr) — search for "교통링크"

**Format:** Same GeoJSON envelope as 교통노드, with road coordinate arrays in `geometry.coordinates`.

**Used by:** `generate_route.py` road graph construction (line 124)

---

### 4. `통과노선/정류장별_통과노선.json` *(optional)*

Number of existing bus routes passing through each stop. Used to identify transfer stops (stops served by 2+ routes). If absent, the transfer stop fitness term (F10) evaluates to zero.

**Source:** Local city transit authority or manual extraction from TOPIS/BIS data.

**Format:**
```json
[
  { "정류소ID": "220000007", "통과노선수": 3 },
  { "정류소ID": "220000065", "통과노선수": 1 }
]
```

**Used by:** `generate_route.py` (line 102)

## Required supporting files (not in `data/`)

### 5. `llm_response.txt` (project root)

LLM-generated fitness weights used to tune the optimization. This file is gitignored because the weights are user/prompt-specific.

**Format:** One `key: value` pair per line:
```
w1: 0.8
w2: 0.6
w3: 0.9
w4: 0.5
w6: 0.7
w7: 0.5
w8: 0.4
w9: 0.6
w10: 0.8
poi_weights: {"학교": 0.3, "병원": 0.3, "음식점": 0.2, "카페": 0.2}
```

Keys `w1`–`w10` correspond to fitness functions F1–F10 (F5 is unused and ignored).
`poi_weights` keys must match the Korean POI category names used in `bus_stop.csv`.

A sample file is provided as `llm_response_example.txt` in the project root.

---

### 6. `bus_stop.csv` (project root)

POI count data per bus stop. This file **is included** in the repository and was generated by running `POI.py` against the Kakao Local Search API.

To regenerate it (e.g., for a different city), run:
```bash
python POI.py
```
Requires `정류장위치/과천시_버스_정류장_위치.json` and a valid `KAKAO_REST_API_KEY` in `.env`.

---

## API cache

`path_cache.json` (project root) stores Kakao Mobility API responses to avoid repeated calls.
It is gitignored. On first run it will be created automatically; subsequent runs reuse the cache.
